# Obtain reference files

The reference files required for each profile are defined in `profile.yaml` -> `sci_params.reference_files`

Reference files for the preconfigured profiles can be downloaded using the file names in the below manifest:

`https://sm-unrestricted-public.s3.ap-southeast-2.amazonaws.com/somaticcodec/reference-data/refs-v1/manifest.txt`

Example download link:

`https://sm-unrestricted-public.s3.ap-southeast-2.amazonaws.com/somaticcodec/reference-data/refs-v1/gnomad_AF_0.1.bed`
